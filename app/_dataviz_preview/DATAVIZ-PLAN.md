## 二、选型调研（GitHub 成熟度，2026-10-11 实测 gh api）

| 库 | Stars | 许可证 | 最新版 | 维护 | 结论 |
|---|---|---|---|---|---|
| **apache/echarts** | **67.5k** | **Apache-2.0**（可商用） | 6.1.0 | 活跃（2026-10-04 有提交） | ✅ **选它** |
| chartjs/Chart.js | 67.7k | MIT | 4.5.1 | 活跃 | 备选 |
| frappe/charts | 15.1k | MIT | — | 活跃 | 图型太少 |
| apexcharts | 15.2k | MIT | — | 活跃 | 默认 SaaS 风，与纸墨不搭 |
| antvis/G2 | 12.6k | MIT | — | 活跃 | 图形语法强但学习成本高、单文件集成不友好 |
| leeoniya/uPlot | 10.6k | MIT | — | 活跃 | 无饼图/雷达，视觉朴素 |

**选 Apache ECharts 6 的理由：**
1. **唯一全满足**：柱/环/雷达/折线/自定义斜率图/箱线全有 + 中文文档 + tooltip/动效开箱即高级 + canvas 本地渲染（file:// 零网络）+ Apache-2.0 可商用 + Apache 基金会背书（项目生命周期稳）。
2. **v6（2025）刚发布全新默认主题**（官方release 明确 "[theme] New theme for ECharts 6.0"），视觉起点就比 5.x 高一代；6.1.0 为当前稳定版。
3. **单文件集成零构建链**：`echarts.min.js` 1.12MB，照 `pdf.min.js` 先例进 dist 即可，不需要引入打包器——与本项目「单文件 + 构建期补丁」的架构完全兼容。
4. Chart.js 轻 205KB 但无箱线、雷达质感弱、tooltip/主题深度浅；本项目装包已 83MB，1.12MB 本地加载无感知，不值得为体积牺牲表现力。

## 三、落地架构（严格遵守「网页版零改动」铁律）

```
app/src/echarts.min.js   ← 库放桌面仓（网页版仓一个字节不碰，连 pdf 那种放网页版仓根都不需要）
                            build.js dist 复制清单 +1 行 → dist/echarts.min.js
app/src/app.patch.js     ← 新增「数据分析图表引擎」分节：
                            ① 按需加载：首次进入数据分析页动态注入 <script src="./echarts.min.js">
                              （照网页版 tsLoadPdfJs:8503 先例；file:// 本地加载毫秒级）
                            ② 接管渲染：包裹替换 window.renderGradeAnalyticsDetail /
                              drawRangeChart / drawPieChart / drawTrendChart
                              （cmWrapPro 同款 window 函数劫持手法；原实现保留作降级兜底——
                              echarts 加载失败时静默回退原生图表，绝不白屏）
                            ③ 主题引擎：echarts.registerTheme('cmInk')，颜色全部运行时
                              getComputedStyle 读 CSS 变量 → 亮/暗/皮肤三态自适应；
                              MutationObserver 盯 html.class/data-skin，变化即重建图表
app/src/wizard.css       ← 图表卡布局样式（只加不改）
app/_v_desktop_test.js   ← +契约段：dist 带 echarts.min.js / 接管标记 / 主题标记 / 降级兜底
```

- **Pro 锁不受影响**：`switchAnalyticsTab` 仍被 `cmWrapPro` 锁（app.patch.js:1939），接管函数挂在原函数名下，锁粒度不变；新图表全部在锁内。
- **版本节奏**：独立版本号铁律，建议 **v1.3.0**（minor：大功能上线）。

## 五、纸墨风视觉规范（cmInk 主题）

- **色板不发明新色**：全部取自应用既有色——朱砂 `#A63A2B` 主色 + 黛蓝 `#3B6E8F` / 竹绿 `#2F7D5B` / 赭金 `#C08A2D` / 紫藤 `#6B5B95`（现有五档色）+ 青灰 `#7A8B99`。
- 柱体：顶圆角 6px、纵向微渐变；网格：去竖轴线，仅水平细线 `rgba(43,43,51,.05)`；轴文字 `--text-muted` 11px。
- tooltip：纸白卡 `--card-bg` + `--border` 描边 + 软阴影；数字 tabular-nums。
- 动效：900ms cubicOut 逐柱 stagger（高级感一半来自动效节奏）。
- 暗色/皮肤：颜色运行时读 CSS 变量，`html.dark`（--primary #CE6B52）与 qinghua/zhuqing 皮肤自动跟随，MutationObserver 触发重建。

## 七、风险与对策

1. **接管耦合网页版函数名** → 接管前 `typeof window.xxx === 'function'` 检查，失败静默回退原生实现（与补丁表「锚点失配即失败」同思路，但不 die、只降级）。
2. **1.12MB 进 dist** → file:// 本地磁盘加载无感；按需加载只在进数据分析页时发生；dist 断言清单同步。
3. **三态（亮/暗/皮肤）回归** → 主题不存死值全读变量；预览页含亮暗切换实测。
4. **动效性能** → 单页 ≤8 个 canvas 实例，ECharts 增量渲染（v6 特性）兜底；旧机器 dispose 及时。
