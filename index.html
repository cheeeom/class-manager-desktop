常见问题

忘记登录密码怎么办？

桌面版的密码只锁本机，当前版本不提供找回——卸载重装即清空重来。建议养成定期「导出数据」备份的习惯。

换电脑时数据怎么迁移？

旧电脑上「导出全部数据」得到一个 JSON 文件，新电脑安装后，在首启向导或设置里一键导入即可。升级安装不影响已存数据。

真的免费吗？以后会收费吗？

每天要用的带班功能——课表、点名、考勤请假、值日、座次——永久免费，这一条写在产品里、说话算话。2026 年冬起新增「Pro 买断」：学分激励、档案留痕、成绩分析、导出工坊、学期报告，属于新功能新价钱，一次买断、无订阅无内购。

Pro 怎么购买和激活？支持微信 / 支付宝吗？

支持，爱发电下单原生支持微信和支付宝。流程三步：在 App 的 Pro 功能处点「购买激活」复制申请码 → 爱发电下单并把申请码填进留言 → 收到激活码贴进 App 即刻解锁。激活全程离线验签，不联网、不上传任何数据。

换了电脑，Pro 授权怎么办？

Pro 授权绑定设备。重装系统一般不影响；换新电脑每年有 3 次免费重置，用反馈邮箱联系作者即可办理。
