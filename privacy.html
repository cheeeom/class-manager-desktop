隐私政策

更新日期：2026 年 10 月 11 日 · 适用于「班主任工作台」桌面版（含 Microsoft Store 版）与网页版

一句话版本

班主任工作台不收集、不上传、不共享你的任何数据。所有数据（学生名册、成绩、学分流水、工作留痕、荣誉记录等）只保存在你自己的电脑上。

数据存储

桌面版的全部数据以本地存储（localStorage / 本机文件）的方式保存在你的电脑上，不上传到任何服务器。云同步功能默认关闭且需要你主动配置自己的 Git 仓库口令，不开启即完全没有网络传输。

联网行为

应用正常运行不需要联网。仅在以下可选功能触发时才会访问网络：

① 检查更新——访问 GitHub Releases 检索新版本号与安装包；
② 云同步（可选）——你自行配置 Git 仓库后，数据加密同步到你自己的仓库；
③ Pro 自动取码（可选）——购买 Pro 后取码时，向爱发电核对订单并向腾讯云函数换取激活码。

不包含的行为

无广告 SDK、无数据统计埋点、无用户行为追踪、无第三方 Cookie、不读取通讯录/定位/摄像头等系统敏感权限。

数据删除

在应用内「设置 → 危险操作 → 清空数据」即可一键彻底删除本机全部数据，删除后无法恢复（请先导出备份）。
